4. O que é Consciência Situacional (SA)?

A Consciência Situacional (SA) é a percepção dos elementos no ambiente, a compreensão de seu significado e a projeção de seu status no futuro próximo. É um pilar fundamental para operações seguras em aviação agrícola.

Nível 1: Percepção

Identificar o status, atributos e dinâmicas dos elementos relevantes no ambiente. O que está acontecendo agora?

→

Nível 2: Compreensão

Sintetizar os elementos da percepção para entender como eles impactam seus objetivos. O que isso significa?

→

Nível 3: Projeção

Projetar as ações futuras dos elementos no ambiente. O que pode acontecer a seguir?
